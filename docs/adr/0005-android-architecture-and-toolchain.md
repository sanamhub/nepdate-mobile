# ADR-0005: Android architecture and toolchain

- Status: Accepted
- Date: 2026-10-06
- Deciders: Sanam Pakuwal

## Context

As of 2026-10-06: Android 17 (API 37) is stable; Google Play requires target API 36 for new apps and
updates from 2026-08-31. In Nepal (statcounter, September 2026) Android 11 and older are about 14 %
of devices. AndroidX libraries are moving to minSdk 24.

## Decision

**Platform**
- `minSdk 26` (about 96 % global reach; java.time without desugaring; adaptive icons).
  `compileSdk 37`, `targetSdk 37`.
- Kotlin 2.4.x, AGP 9.x (built-in Kotlin), Gradle 9.x, JDK 17, version catalog
  (`gradle/libs.versions.toml`), configuration cache on.

**Libraries (complete list)**

| Purpose | Library |
|---|---|
| calendar logic | `nepdate-kotlin`: `io.github.sanamhub:nepdate` and `io.github.sanamhub:nepdate-patro` (hub ADR-0004) |
| UI | Compose BOM (latest stable), `material3` **stable** (1.4.x; Material 3 Expressive only after 1.5.0 is stable), `activity-compose` |
| navigation | Navigation 3 (1.2.x) |
| state | `lifecycle-viewmodel-compose`, coroutines/Flow |
| settings | Preferences DataStore (1.2.x, multi-process: app + widget) |
| widgets | Glance `glance-appwidget` (1.2.x stable), `glance-material3` |
| start-up | `profileinstaller` (Baseline Profile) |
| tests | JUnit, Compose UI test, Roborazzi (screenshots), Turbine, Macrobenchmark and UI Automator (`:baselineprofile` only) |

Gradle plugins (complete list): Android Gradle Plugin, Compose compiler, `androidx.baselineprofile`,
Roborazzi, ktlint (`org.jlleitschuh.gradle.ktlint`), detekt, Gradle Play Publisher (ADR-0009).
Test coverage uses AGP's built-in JaCoCo (`enableUnitTestCoverage`), not Kover.

No Hilt, Koin, Room, WorkManager, AppCompat, Firebase or Google Play Services. Dependency injection
is manual: an `AppContainer` on the `Application`.

**Structure:** a single `:app` module (calendar logic lives in the library). Packages
`ui.month`, `ui.day`, `ui.upcoming`, `ui.converter`, `ui.settings`, `widget`, `schedule`, `data`
(settings), `di`.

**Platform behaviour**
- `enableEdgeToEdge()`, `WindowInsets`; predictive back via Navigation 3.
- Per-app language: `generateLocaleConfig = true`, `res/resources.properties`
  (`unqualifiedResLocale=en-US`), `values-ne/`; the in-app language picker uses
  `LocaleManager` on Android 13+ and is hidden below 13 (no AppCompat).
- Dynamic colour on Android 12+ for surfaces; `holiday` and `today` colours fixed (design system §2).
- Devanagari from the system font (Noto Sans Devanagari). Android 16 ignores `elegantTextHeight`:
  the M0 spike checks vowel signs for clipping in widgets.

**Build**
- R8 full mode and resource shrinking in release; Baseline Profile generated by the Macrobenchmark
  module `:baselineprofile` (a test-only module).
- **Reproducible release builds** for F-Droid/IzzyOnDroid: `vcsInfo { include = false }`, fixed JDK,
  no build timestamps, PNG crunching off, Baseline Profile checked in (ADR-0009).

## Consequences

- Smallest dependency set that still gives Material 3, widgets and settings shared with widgets.
- A CI check fails if the merged release manifest contains `android.permission.INTERNET` (ADR-0007).
