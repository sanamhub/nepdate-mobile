# Play content-rating answers

Draft for the IARC content-rating questionnaire. Applies to `np.nepdate`, versionCode 1. The app is
a calendar and reference tool. It has no user-generated content and no social features.

| Category | Answer |
|---|---|
| Violence, blood or injury | No |
| Sexuality or nudity | No |
| Profanity or crude language | No |
| Controlled substances, alcohol or tobacco | No |
| Gambling or simulated gambling | No |
| Fear, horror or disturbing content | No |
| User-generated content or user-to-user interaction | No |
| Sharing of user location | No |
| Digital purchases or in-app purchases | No |
| Advertising | No |
| Unrestricted web access | No |
| Account creation or login | No |

Expected rating: Everyone / 3+ or the local equivalent. This is an expectation, not an issued
certificate. Enter the answers in Play Console and use the certificate IARC returns.

## Notes for the reviewer

- Holiday and event names come from the bundled calendar data. They are not user-generated.
- The app opens external links in the system browser. It has no embedded web view.
- The app does not collect analytics, crash reports or advertising identifiers.
- A3-04 is the human gate for submitting the questionnaire and publishing the listing.
