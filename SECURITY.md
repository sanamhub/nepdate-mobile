# Security policy

## Supported versions

Only the latest release of each app receives security fixes. The Android app is distributed on
Google Play, F-Droid, IzzyOnDroid and GitHub Releases. The iOS app is distributed on the App Store.

## Reporting a vulnerability

Do not open a public issue. Use GitHub's private vulnerability reporting:

https://github.com/sanamhub/nepdate-mobile/security/advisories/new

Include the app, the version, the device and OS, and the steps to reproduce the problem. You should
get a reply within 7 days.

If the report concerns a wrong date, holiday or tithi, say so. The calendar data comes from
[sanamhub/nepdate](https://github.com/sanamhub/nepdate), so a data fix goes there first
(ADR-0003).
